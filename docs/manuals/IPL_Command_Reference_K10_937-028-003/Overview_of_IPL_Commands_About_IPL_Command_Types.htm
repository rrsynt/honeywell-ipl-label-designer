About IPL Command Types

There are six types of IPL commands.

Commands Description
Communications Commands Set printer communications parameters.
Configuration Commands Enable or disable printer features and options. For RFID, use Configuration commands to determine how the RFID tags interact with the printer. To use Configuration commands, the printer must be in Print operating mode.
Immediate Commands Get status information from the printer, reset the printer, or stop print jobs. To use Immediate commands, the printer can be in any operating mode.
Print Commands Use these commands to download data to the printer and print bar code labels. For RFID, use Print commands to write data to and read data from RFID tags and to print RFID tag labels. To use Print commands, the printer must be in Print operating mode.
Program Mode Commands Use these commands to design bar code label formats. RFID program mode commands create and define data sources for tag fields. To use these commands, the printer must be in Program operating mode.
Test and Service Commands Use these commands to get diagnostic information from the printer when troubleshooting or configuring the printer.To use these commands, the printer must be in Test and Service operating mode.
